## オートマウスレイヤ機能

このリポジトリでは、オートマウスレイヤ機能が有効になっています。

### 機能説明

トラックボールを操作すると、自動的にレイヤー1（auto_mouse_layer）に切り替わります。
マウス操作を停止してから2秒後に自動的に元のレイヤーに戻ります。

### 設定内容

以下の設定が有効になっています：

1. **CONFIG_ZMK_POINTING=y** - ポインティングデバイスのサポートを有効化
2. **zip_temp_layer 1 2000** - トラックボール操作時にレイヤー1を2秒間有効化

### ユーザー側の設定

ユーザー側で特別な設定は不要です。ファームウェアを書き込むだけで、オートマウスレイヤ機能が動作します。

### カスタマイズ

レイヤー1（auto_mouse_layer）のキーマップは `config/keymap.keymap` で編集できます。
デフォルトでは、マウスボタン（左クリック、右クリック、中クリック）が配置されています。
